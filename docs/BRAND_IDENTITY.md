# Infame / إنفيم brand identity

Founder-selected on2026-10-06: `/` is the primary public website. `/classic`
remains a retained reference. The approved landing page and its overlapping
circles, charcoal dot and eight-point spark define the shared identity.

The original Talaqee platform composition remains authoritative: keep its sidebar,
header, spacing, tables and form cards. Apply this identity through shared colors,
quiet accent details and the reusable motif rather than rebuilding its layout.

| Token | Color | Use |
| --- | --- | --- |
| `--infame-yellow` | #fffc00 | Primary actions and collaboration circle |
| `--infame-coral` | #f58529 | Warm gradient origin |
| `--infame-rose` | #dd2a7b | Gradient midpoint |
| `--infame-purple` | #8134af | Gradient end, focus and quiet accents |
| `--infame-ink` | #121214 | Light-mode typography, dot and spark |
| `--infame-paper` | #faf9f4 | Approved light background |

Use `InfameBrandPattern` for the unchanged landing artwork or its compact shell
variant. Keep it decorative/aria-hidden, leave all controls labelled and preserve
reading order in360px Arabic RTL and English LTR. Dark mode adapts neutral ink and
overlap contrast through existing semantic tokens. Success/error colors retain
their meaning. IBM Plex Arabic/Latin remain the shared typography; never letter
space Arabic or place decorative shapes over content and focus targets.

Portable saved assets are `public/brand/infame-pattern.svg` and
`public/brand/infame-palette.json`. The SVG is a transparent vector master; the
shared component preserves the existing landing CSS geometry. Future UI, Studio
components, campaign profiles and media/voice surfaces consume the same tokens.
Marketing copy must reflect actual managed-campaign/provider readiness; this
identity approval does not imply publication, legal verification or paid activation.
